# Exterior models

Scanned plants, rocks and props from [Poly Haven](https://polyhaven.com/models) (CC0), downloaded at 1k
texture resolution and converted from glTF to FBX in Blender.

Trees (`island_tree_02`, `tree_small_02`, `jacaranda_tree`) were 1-4 M triangles, far too heavy for Quest.
They were reduced to ~75k triangles by keeping a random subset of leaf clusters (scaled up to keep the canopy
full) and decimating the wood. Each also has a `_Impostor` mesh: two crossed quads textured with
orthographic front/side renders of the full tree. `Tree_*.prefab` switches between the two with an LODGroup,
and the distant tree line uses impostors only.

Ground, road, pavement and fence textures are in `Assets/Textures/Exterior` (Poly Haven, CC0).
Everything else (road, fence, neighbouring houses, lamps) is generated by
`Smart House > Exterior > 2. Build Exterior` (`Assets/Editor/SmartHouseExterior.cs`) into `Generated/`.

# Controller models

`Assets/Models/Controllers` holds the Meta Quest 3 (Touch Plus) controller models from the WebXR input
profiles asset set (`@webxr-input-profiles/assets`, profile `meta-quest-touch-plus`, MIT licence).
